# Exercise 7 — Abstraction: Inventory System

This exercise is intentionally conceptual.

The inventory needs to know only the essential information and common operation(s) it can rely on. For example, it might need to know that an object can be used, while not knowing how a Potion restores health, how a Weapon is equipped, or how a QuestItem affects a quest.

The exact abstraction is intentionally open.

Do not implement an interface or abstract class for this exercise.
